## 2. AI Configuration (এআই কনফিগারেশন)

অ্যাপটিতে ডুয়াল ইঞ্জিন রয়েছে:
1. **Instant Studio Engine (Local High-Resolution Engine):** কোনো ইন্টারনেট বা API Key ছাড়াই ডিভাইসেই দ্রুত নিখুঁত ডাই-কাট বর্ডার, আর্ট ফিল্টার এবং কমিক এক্সপ্রেশন ব্যাজ তৈরি করে।
2. **Google Gemini AI Engine (Cloud):** ক্লাউড-বেজড ইমেজ জেনারেশনের জন্য `gemini-2.5-flash-image` মডেল সমর্থিত।
   - আপনি চাইলে অ্যাপের উপরের ডান পাশের ✨ আইকনে ক্লিক করে সরাসরি নিজের Gemini API Key যুক্ত করতে পারেন।
   - অথবা `.env` ফাইলে `GEMINI_API_KEY=YOUR_KEY` দিয়ে বিল্ড করতে পারেন।

## 3. Technology Stack (প্রযুক্তি)

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM + Clean Architecture + StateFlow
- **Image Pipeline:** Android Graphics Canvas + MediaStore + Coil
- **Archive Engine:** Java `ZipOutputStream`
- **AI Integration:** Google Gemini API (`gemini-2.5-flash-image`) + Retrofit
- **Build System:** Gradle (Kotlin DSL) + Android Gradle Plugin 9.1.1
